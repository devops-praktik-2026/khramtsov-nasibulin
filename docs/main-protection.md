## Настройки GitHub

Обновлено существующее правило [Защита main](https://github.com/devops-praktik-2026/khramtsov-nasibulin/rules/23659601).

- Правило активно и применяется к основной ветке (`~DEFAULT_BRANCH`, сейчас `main`).
- Список обхода пуст, в том числе для администратора.
- Все изменения требуют PR и одного одобрения второго участника.
- Новые изменения сбрасывают устаревшее одобрение; обсуждения должны быть разрешены.
- Допускается squash-слияние.
- Force push и удаление основной ветки запрещены.
- Обязательные проверки от GitHub Actions: **Стиль кода**, **Тесты**, **Сборка образов**, **Поиск паролей**, **Публикация образа**.

Публикация образа выполняется при push в main; в PR это задание имеет штатный статус `skipped`.

## Проверка прямого push

В отдельном checkout от актуальной main создан коммит `72c07624e99a22e5dc32c37ac478bffce04e2d6a` с проверочной строкой README. Выполнена настоящая команда `git push origin HEAD:refs/heads/main`.

GitHub отклонил отправку (код завершения 1):

```text
GH013: Repository rule violations found for refs/heads/main.
Changes must be made through a pull request.
5 of 5 required status checks are expected.
```

SHA main до и после попытки одинаковый: `cf5dcb663d9118cac412c7184e1e474c4c5f5ce6`. Проверочный коммит не входит в ветку этого PR.

## Проверка PR с упавшим стилем

В коммите `6d53db465c9161e12c41b4a8703dc74b309716f9` временный файл `scripts/_main_protection_probe.py` содержал заведомую ошибку форматирования `probe=1`.

[Проверка «Стиль кода»](https://github.com/devops-praktik-2026/khramtsov-nasibulin/actions/runs/40871852360/job/123440621216) завершилась с `FAILURE`: Ruff сообщил, что файл требует форматирования. GitHub вернул `mergeStateStatus: BLOCKED`. В этой же стадии одобрение тоже отсутствовало (`REVIEW_REQUIRED`); требование обязательной проверки дополнительно подтверждено сохранёнными настройками ruleset.

После фиксации результата временный файл удалён.

## Проверка PR без одобрения

Для проверки отдельно от ошибки стиля временный файл удаляется, затем ожидается завершение обязательных проверок. При четырёх результатах `SUCCESS` и штатном `SKIPPED` публикации GitHub должен продолжать возвращать `REVIEW_REQUIRED` и `BLOCKED`.

Фактические результаты этой стадии, SHA коммита и ссылки на CI сохраняются в [описании PR #34](https://github.com/devops-praktik-2026/khramtsov-nasibulin/pull/34). Содержательный комментарий, одобрение и слияние выполняет напарник по правилам проекта.

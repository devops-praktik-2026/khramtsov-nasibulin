# Контракт HTTP API сервиса заказов

Машинно-читаемая версия контракта находится в
[`orders-api.yaml`](orders-api.yaml) в формате OpenAPI 3.1. Её можно открыть
в Swagger UI или использовать для генерации клиентов и тестов.

## Маршруты

| Метод и путь | Назначение |
| --- | --- |
| `POST /orders` | Создать заказ для существующего клиента. |
| `GET /orders/{order_id}` | Получить заказ по номеру. |
| `GET /orders?account_id=...&limit=...&offset=...` | Получить заказы клиента с ограничением выдачи. |

OpenAPI-файл описывает поля запросов и ответов, ограничения, примеры и все
согласованные коды ошибок (`404`, `422`, `503`). Для списка заказов отдельно
зафиксировано, что у клиента без заказов возвращается пустой список с кодом
`200`.

## Как меняется контракт

OpenAPI-файл является источником истины. Любое изменение контракта вносится
только через pull request в `main`. В pull request нужно описать причину
изменения, затронутые запросы и совместимость с текущими клиентами; прямые
изменения в `main` для этого файла не используются.
